TWIBBON MUSAMMA 2026 - WEBSITE STATIS

Isi folder:
- index.html : halaman twibbon dengan unggah foto, geser, zoom, dan unduh PNG.
- twibbon.png : bingkai twibbon transparan.

CARA MEMASANG DI GITHUB PAGES:
1. Buat repository GitHub bernama twibbon-musamma-2026 dan pilih Public.
2. Upload index.html dan twibbon.png ke root repository (jangan di dalam subfolder).
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih Branch: main dan folder: /(root), lalu Save.
6. Tunggu proses deployment selesai. URL biasanya:
   https://USERNAME.github.io/twibbon-musamma-2026/
   Ganti USERNAME dengan username GitHub milikmu.

Fitur:
- Foto diproses di browser pengguna, tidak dikirim ke server.
- Bisa menggeser foto dengan jari/mouse.
- Bisa mengatur zoom.
- Unduh hasil PNG tanpa watermark.
